## Metronome

Use the compact practice row for BPM, −1/+1 and Start/Stop; the chevron opens shared controls for 2/4, 3/4, 4/4, 5/4, 6/8 or 7/8, Accent first beat (Off by default), and Sound + Flash / Sound only / Flash only. The running meter remains available while collapsed; the entire Stop click button pulses with each flash-enabled beat in practice and Tools. Opening/closing restores the prior Description/Reference, PDF page/zoom and Notes draft without restarting practice or recording. Tools → Metronome provides the same controls and clock.

For 6/8 and 7/8, BPM counts each eighth note: six or seven clicks per bar, without grouped/dotted-quarter mode. Meter/accent/output changes take effect on the next beat; BPM retains phase. Flash follows the audio playback clock; actual display/speaker latency can differ. Silent mode silences click PCM. Tools → Audio Settings saves four click timbres, output default and a shared completion alarm (four sounds or Off) for Block and foreground countdown timers; previews stop on leave/background. Active capture suppresses completion audio.

## Focused Practice transport and Notes

Description and Reference retain their shared workspace; Description starts open and switching sections always leaves one open. Notes is a footer pill beside the practice actions; Save for later and its row are removed. Opening a transport panel temporarily hides both contents, retains both headers and gives the panel the space. Closing restores the prior workspace choice, including PDF page/zoom. Tapping either workspace header while a panel is open collapses it and opens that section; active capture continues with pinned Stop, and collapsed temporary review keeps Save and a full-review button. Only one transport panel opens. Compact tinted recording controls/selection, timer/metronome and primary actions remain.

Notes opens Add New Note with the Block's newest-first collapsible history across sessions. Save Note adds an independent timestamped entry, clears the editor after commit and keeps Notes open; Return to Practice closes separately. Expand a saved new/legacy note for Edit, Save Changes or Cancel Changes; original creation/session date and timing stay unchanged. Drafts survive panel switches and leaving unsaved text asks before discarding. Legacy notes are marked Earlier session because their actual creation timestamp was not stored. Room11 and JSON7/readers1–7 preserve old/new notes independently; descriptions, overall session notes and daily Log remain separate.

A running Block crossing its configured duration plays a short two-note cue through the existing media AudioTrack path, briefly ducking a running click while retaining BPM/beat phase. It stops at zero and still requires explicit Continue for overtime or Complete. It never marks a Block finished or replays from reopening/recomposition. Device media volume/routing determine physical audibility.

The banner returns Home. During practice, banner and Android Back open **Leave current session?**: Continue stays put; Back to Main pauses/checkpoints and saves the note before navigation. Save failure remains recoverable on the same screen. Stop/Save or cancel an active recording before confirming exit. Unsaved Block/Goal/Routine editors reuse their discard safeguards; Log retains its save barrier. Current candidate/release verification is in CURRENT_STATE.md.

## Using the app

- **Blocks:** create/edit with required Name/Action, default duration and optional tempo/notes. Search name/action/notes literally, switch Active/Archived, Archive/Restore, or select Delete Permanently in a saved Block's editor.
- **Reference image or PDF:** save a Block, reopen its editor and choose Add image or PDF from Android’s document picker. One JPEG/PNG/WebP (up to 40 megapixels/16384px per side) or unencrypted PDF (1–100 pages), up to 20 MiB, is copied into private storage. Show reference/Hide reference reveals it inline. PDFs start at page 1; use Previous page/Next page and the page counter. Pinch to zoom up to 6×, drag while enlarged and use Reset image zoom or Reset PDF zoom. Page changes reset zoom. Camera orientation and the full safe-width, bounded portrait region (180–640dp) remain supported. Use Replace reference image/PDF to choose either type, or Remove reference image/PDF and confirm. Canceling or failed imports keep the current reference; archived Blocks retain ownership. Missing/unreadable files show Retry reference and can be replaced/removed in the editor. A PDF must render successfully before replacing the old file.
- **Safe deletion:** unused active or archived Blocks can be deleted after confirmation. An attached image or PDF, Goal links, saved Routines, recordings and all draft/unfinished/completed session entries protect the Block. Remove the reference deliberately in the editor before permanent deletion. Refusal shows persistent counts and explains completed history. Associations/audio/history are never removed automatically; use Archive when dependencies remain.
- **Practice Now:** build a session, reorder placements and override their durations, or select an unfinished session. Starting fresh retains older unfinished practice and the shared builder draft. Focus starts paused; Start/Resume, Pause, Complete and Skip record foreground active time. At zero a short two-note cue sounds (media output permitting), then choose Continue for overtime or Complete. Header/Back opens a confirmation; Back to Main saves and pauses before Home, and restart resumes paused.
- **Notes and history:** Timestamped Block notes require Save Note; edits require Save Changes. Leaving unsaved new/edit text offers a discard guard. Session notes require Save note; leaving an edited summary asks before discarding. Routines retains Recent Practice and reopenable summaries with historical instruction snapshots.
- **Saved Routines:** reusable ordered Block references with independent durations, create/edit/reorder/delete, builder Save as Routine, and independent fresh starts. Archived or unavailable references prevent starting until repaired/restored.
- **Goals:** up to five active Goals, manual percentage/notes/outcome, priority, top-two Home progress bars, completion/reopen, shared Block links and Goal practice. Displayed practice time uses actual explicitly attributed sessions; it does not automatically set progress.
- **Recordings:** Show reference within a Block’s recording sheet opens the same image/PDF inline, including during free capture and phrase count-in/capture. Hide, zoom, pan and page changes keep the sheet and recording active. Active status and Stop and review take/Cancel phrase stay above scrolling references. Stop opens temporary **Review Take** with Play/Stop Preview, Save, Re-record and Discard in Focused Practice, saved-Block recording and standalone Free Recording. Only successful Save adds to permanent saved takes. A complete phrase also awaits review without automatic playback; incomplete phrases are discarded. Close recordings asks before discarding review audio. Background stops capture/playback without auto-saving or restarting; valid free audio can remain for review within the process. Process loss discards unsaved temporary audio on recovery. Existing saved takes remain intact; recording never runs in the background. Standalone Free recording has no Block reference. Each Block retains multiple free M4A takes and fixed-phrase WAV loops; Full recording management is available in the saved Block editor, including archived Blocks, and main Recording; Focused Practice uses compact selectors. Record phrase supports 30–300 BPM, any whole loop length of 1–64 beats (4/8/16/32 shortcuts), a positive user-entered count-in (default 4), and optional Click while recording (on by default). Takes support playback, rename, confirmed deletion and per-take export. Recording also provides standalone Free recording and Saved free recordings without creating a synthetic Block. Audio stops on leave/background and never restarts automatically.
- **Log:** Home → Log opens today in your local calendar. Write freely; text saves automatically. Wait for Saved. Choose date to revisit and edit any day. Weekly View displays Monday–Sunday from the same entries; Previous/Next week navigate, and tapping a day opens its editor. Back returns from the week to the daily editor; The banner saves before leaving. If saving fails, the text stays in the editor for Retry. Returning on another day opens that day without changing earlier text.
- **Tools:** standalone metronome, chromatic microphone tuner, stopwatch/countdown and Backup and restore. The practice click and Block timer are independent. Tools → Audio Settings persists the default loop count-in; each loop can override it. Count-ins must fit the 15-minute execution budget at selected BPM. Shared metronome sound/output and completion alarm choices also persist; optional dark mode is deferred. The green banner, cream surfaces, Lato and banner navigation are shared throughout app screens.

## Backup and important limits

Tools → Backup and restore exports **format-7 UTF-8 JSON**, reading versions **1–7**. It protects independent dated Logs, Blocks, Routines, Goals, sessions, placements, notes and saved recovery state. A Log-only installation is nonempty and protected from restore. Restore validates references/state and inserts atomically into a completely empty app; it never merges or replaces existing data. Use a spare empty installation for restore testing.

**JSON excludes all reference images/PDFs and attachment metadata and every recording, take label and take metadata row. Keep original images and PDFs separately and reattach after restore. Export wanted takes individually.** Clearing/uninstalling the app or losing the device destroys its private reference files; platform backup/device transfer excludes this app’s media. No image export or media-inclusive bulk restore is provided. There is no full audio-inclusive restore/import. Wait for Backup saved; failed exports may leave incomplete documents. Save notes before exporting. See [BACKUP_FORMAT.md](BACKUP_FORMAT.md).

Only committed foreground practice time is recovered. Abrupt death/storage failure can lose the latest uncommitted timer interval or unsaved text. Acoustic timing, tuner accuracy, loop onset/boundaries, vendor document providers and TalkBack need physical-phone checks.
