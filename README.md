# practice.logger

An offline Android practice app built with Kotlin, Jetpack Compose, Room and locally bundled Lato. Current signed release: **0.15.0/build 30**, adding PDF references and inline reference viewing while recording. Compact Block headings and upright, wide photo references are retained. Daily Log/Weekly View is retained. Exact verification and limitations are in CURRENT_STATE.md.

## Using the app

- **Blocks:** create/edit with required Name/Action, default duration and optional tempo/notes. Search name/action/notes literally, switch Active/Archived, Archive/Restore, or select Delete Permanently in a saved Block's editor.
- **Reference image or PDF:** save a Block, reopen its editor and choose Add image or PDF from Android’s document picker. One JPEG/PNG/WebP (up to 40 megapixels/16384px per side) or unencrypted PDF (1–100 pages), up to 20 MiB, is copied into private storage. Show reference/Hide reference reveals it inline. PDFs start at page 1; use Previous page/Next page and the page counter. Pinch to zoom up to 6×, drag while enlarged and use Reset image zoom or Reset PDF zoom. Page changes reset zoom. Camera orientation and the full safe-width, bounded portrait region (180–640dp) remain supported. Use Replace reference image/PDF to choose either type, or Remove reference image/PDF and confirm. Canceling or failed imports keep the current reference; archived Blocks retain ownership. Missing/unreadable files show Retry reference and can be replaced/removed in the editor. A PDF must render successfully before replacing the old file.
- **Safe deletion:** unused active or archived Blocks can be deleted after confirmation. An attached image or PDF, Goal links, saved Routines, recordings and all draft/unfinished/completed session entries protect the Block. Remove the reference deliberately in the editor before permanent deletion. Refusal shows persistent counts and explains completed history. Associations/audio/history are never removed automatically; use Archive when dependencies remain.
- **Practice Now:** build a session, reorder placements and override their durations, or select an unfinished session. Starting fresh retains older unfinished practice and the shared builder draft. Focus starts paused; Start/Resume, Pause, Complete and Skip record foreground active time. At zero, choose Continue for overtime or Complete. Save for later/Back saves and pauses; restart resumes saved practice paused.
- **Notes and history:** Quick Block notes save via Save Block note, Save for later, Back, Complete or Skip. Session notes require Save note. Routines retains Recent Practice and reopenable summaries with historical instruction snapshots.
- **Saved Routines:** reusable ordered Block references with independent durations, create/edit/reorder/delete, builder Save as Routine, and independent fresh starts. Archived or unavailable references prevent starting until repaired/restored.
- **Goals:** up to five active Goals, manual percentage/notes/outcome, priority, top-two Home progress bars, completion/reopen, shared Block links and Goal practice. Displayed practice time uses actual explicitly attributed sessions; it does not automatically set progress.
- **Recordings:** Show reference within a Block’s recording sheet opens the same image/PDF inline, including during free capture and phrase count-in/capture. Hide, zoom, pan and page changes keep the sheet and recording active. Active status and Stop and save take/Cancel phrase stay above the scrolling content. Close recordings and genuine app backgrounding retain their existing stop/save-or-discard behavior; recording never runs in the background. Standalone Free recording has no Block reference. Each Block retains multiple free M4A takes and fixed-phrase WAV loops; Recordings is available in practice and the saved Block editor, including archived Blocks. Record phrase supports 30–300 BPM, 4/8/16/32 beats, four count-in clicks and optional Click while recording (on by default). Takes support playback, rename, confirmed deletion and per-take export. Recording also provides standalone Free recording and Saved free recordings without creating a synthetic Block. Audio stops on leave/background and never restarts automatically.
- **Log:** Home → Log opens today in your local calendar. Write freely; text saves automatically. Wait for Saved. Choose date to revisit and edit any day. Weekly View displays Monday–Sunday from the same entries; Previous/Next week navigate, and tapping a day opens its editor. Back returns from the week to the daily editor; Back to Home saves before leaving. If saving fails, the text stays in the editor for Retry. Returning on another day opens that day without changing earlier text.
- **Tools:** standalone metronome, chromatic microphone tuner, stopwatch/countdown and Backup and restore. The practice click and Block timer are independent. The green banner, cream surfaces, Lato and prominent Back to Home controls are shared throughout app screens.

## Backup and important limits

Tools → Backup and restore exports **format-6 UTF-8 JSON**, reading versions **1–6**. It protects independent dated Logs, Blocks, Routines, Goals, sessions, placements, notes and saved recovery state. A Log-only installation is nonempty and protected from restore. Restore validates references/state and inserts atomically into a completely empty app; it never merges or replaces existing data. Use a spare empty installation for restore testing.

**JSON excludes all reference images/PDFs and attachment metadata and every recording, take label and take metadata row. Keep original images and PDFs separately and reattach after restore. Export wanted takes individually.** Clearing/uninstalling the app or losing the device destroys its private reference files; platform backup/device transfer excludes this app’s media. No image export or media-inclusive bulk restore is provided. There is no full audio-inclusive restore/import. Wait for Backup saved; failed exports may leave incomplete documents. Save notes before exporting. See [BACKUP_FORMAT.md](BACKUP_FORMAT.md).

Only committed foreground practice time is recovered. Abrupt death/storage failure can lose the latest uncommitted timer interval or unsaved text. Acoustic timing, tuner accuracy, loop onset/boundaries, vendor document providers and TalkBack need physical-phone checks.
