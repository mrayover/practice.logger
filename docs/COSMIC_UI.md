# UI-C1 — centered primary headings and Cosmic

Cosmic is opt-in through the existing Settings → Appearance selector. Stable ID `cosmic` persists through ThemePreferences; Light, Dark, Smooth, Sunny, Orchid and Submarine retain their original palettes. System Default remains last and continues to resolve the device appearance. MainActivity applies the native Cosmic style before startup/recovery, updates bars/window colors in place and retains existing audio owners.

Cosmic uses a deep navy-to-violet gradient with light-blue primary actions, lavender selection/secondary roles, pale violet tertiary accents and light text. Warning/error roles inherit the original Dark palette. All five historical Goal colors are unchanged. Opaque input, dialog, transport and media/editor work surfaces retain contrast. Original image/PDF pixels and waveforms are not tinted.

ApplicationBackground supplies one noninteractive cached drawing layer behind the root Surface.96 seeded normalized stars are generated once, with fixed positions, small varied radii and mostly low opacity. Gradient, glow, positions and pixel radii are cached by drawing size/density; scrolling and unrelated recomposition do not regenerate randomness. No image assets, network, animation, timer or background work. The root Surface explicitly supplies onBackground text color when transparent. Home's opaque page fill is transparent only for Cosmic; prior themes retain their fills.

PageHeading centers primary titles across the complete content width, preserves existing sizes and Lato, and adds heading semantics. Coverage: Home's already-centered Goals; Practice Now/unfinished sessions, Block Library/editor, Goals/detail/editor/associated Blocks, This Week/Prepare Week, session builder/Block picker, both Routine entry points/editor, Tools/tool pages/Piano, Recording/management, standalone and selected-audio Transcribe, Media Library/pickers/audio/visual previews, Inspirations/list/editor/detail, Log/Weekly View, Playground, Statistics, practice Ready/Up Next/focused Block, Block/session reflections and Session Summary, Backup and Settings. Audio Settings is a subsection within the shared Settings page; its label and other subsection/form/body text retain existing alignment. Banner branding is unchanged.

Editor titles reserve equal measured space on each side for More; new editors need no reservation. Media viewers place titles below existing Back controls. Long ordinary titles wrap naturally; constrained editor/viewer titles use at most two lines and ellipsis, and compact Focused Practice uses one line with full text retained in semantics. The timer remains on its existing row, before the full-width compact name; existing measured-header/transport constraints and pinned actions remain. No additional scrolling container is introduced.

Verification is scoped to palette/preference/star bounds checks and one API35 visual workflow. It samples Settings/recreation/switch-back,320dp/200% representative navigation/dynamic titles, timer visibility, earned Playground color/selection/pan and shared waveform/input surfaces. It is not F1, a cross-feature regression, acoustic acceptance or a physical-phone signoff. Exact delivery evidence is maintained in [CURRENT_STATE](../CURRENT_STATE.md).
