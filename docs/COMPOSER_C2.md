## Editing on a landscape phone

Open Tools → compose.logger, create/open a composition and wait through the centered white identity on black. The dedicated Activity requests landscape. The entrance counts at least3,000ms of resumed, focused displayed time, beginning after initial rendering; recomposition does not reset it. Saved remaining time survives ordinary recreation. Background time and loss of window focus do not count. Back uses the normal dirty-project barrier and file loading is independent of entrance rendering.

For an empty C1 project, choose **Create piano patterns A/B**. Instrument selectors and Pattern A/B switch the visible editor. **+ Pattern** adds only a missing A/B/C slot; **+ Instrument** adds another Reference Piano track with A/B, up to the model's eight-track limit. C3 adds a Sound picker and basic mixing to these minimal navigation controls, without full C4 management. Existing track/pattern IDs and instrument references are preserved.

- **Draw:** tap empty grid to create one note. Tap a note to select/audition it. Drag its left/body area to move it; selected groups retain their offsets. Drag the right end to resize that note. The resize region extends12dp past the end and includes up to22dp inside it. Zoom in for dense thirty-second notes. Double-tap a stationary note within300ms to delete it. A drag clears double-tap history and never inserts another note.
- **Select:** drag empty grid to box-select intersecting notes; a tap on empty space clears selection and creates nothing. Tap an individual note to select it. Selected notes are gold with a white outline. **Actions** opens a Material3 dropdown containing **Select All**, **Copy**, **Paste**, **Delete Selected** and **Quantize Selected**, in that order. Copy/Delete/Quantize require selection; Paste requires a nonempty clipboard/editable pattern. Each command dismisses the menu.
- **Two fingers on the grid:** pan horizontally/vertically and pinch to zoom horizontally. A second pointer cancels an uncommitted note preview/selection rectangle. Gesture ownership remains navigation until every pointer lifts. Keys support independent polyphonic finger tokens. Tap/hold auditions; vertical dragging beyond Android touch slop takes scroll ownership, releases held audition and changes only panY until release. No glissando occurs during scrolling. **Hand** pans the grid with one finger without editing.
- **Grid** chooses1/4,1/8,1/16,1/32,1/8T,1/16T or1/32T (960,480,240,120,320,160 or80 ticks). **Duration** independently sets the next note's duration. **Snap** affects subsequent insertion/movement/resizing only. Off permits single-tick timing. Changing grid or snap never rewrites existing notes. Quantize is an explicit undoable selected-start operation.
- Drag/tap the top ruler to move the red insertion/paste cursor independently of notes. Ruler labels use the actual project meter/bar boundaries. The cursor is measured in960 PPQ ticks. C3 adds a separate green consumed-audio playhead; the red insertion cursor retains these semantics.
- Paste anchors the earliest copied onset at the cursor and preserves all relative timing, pitches, durations and velocities. Every pasted note gets a fresh UUID; overlapping notes coexist. Clipboard stays available while switching patterns and instruments in Loop mode. Copy never removes the source. Undo spans pattern switches and includes creation, move, resize, delete, paste, quantize, settings, pattern creation and length changes. One drag commits one operation. The bounded100-entry history is session-local, with no branching/redo.
- Choose1,2,4,8 or16 bars. Shortening is refused with an explanation if notes would be excluded. No notes are silently truncated/deleted. Paste may grow the destination to the smallest permitted length that fits; it refuses beyond16 bars. Inserted durations are bounded at the pattern end; drag movement preserves durations and fits the group within its pattern.

Header/control strips scroll horizontally at narrow widths or enlarged text; the note area retains the remaining height. Use Hand or two fingers to navigate the grid itself, with on-screen Zoom−/+ as an additional horizontal zoom control. Android can override orientation in large/multiwindow configurations; widen/rotate the window when needed.

## Persistence, lifecycle and audio

The unchanged strict v1 project codec represents exact note ID/pitch/startTick/durationTick/velocity and stable track/pattern ownership. Empty C1 projects remain valid and are not implicitly filled on load. Saved project files continue through C1's validated synced staging, same-directory atomic rename/read-back and revision conflict protections. No practice database, practice backup, Media Library, timer or session relationship changes.

Musical edits immediately update the visual project. Full drafts checkpoint in order on IO to `files/composer/drafts/<session UUID>.json`, with synced staging and atomic replacement; the Activity bundle holds only the draft identity, entrance remainder and small view state. Recovery validates the draft against the saved project ID/revision/creation time. Explicit Save clears its checkpoint only after durable project save. Save errors retain the current draft. Dirty Back offers Save/Discard/Keep editing. Undo snapshots use the current committed revision after Save, preserving optimistic locking. Undo history and the in-memory clipboard do not survive process death; committed musical data and restored drafts do. Sudden process death before an asynchronous checkpoint completes can lose the most recent unsaved gesture; explicit Save is the durability boundary.

C3 replaces Composer audition with the selected SoundFont instrument and an independent single-worker audio/focus owner. Reference Piano outside Composer is unchanged. MIDI0–127 is accepted; melodic edge samples are extrapolated. Keyboard tokens support chords/release, and scrolling releases audition without editing notes. Background/focus/noisy/disposal safeguards stop all output. See [C3 ownership, timing and limits](COMPOSER_C3.md).

Existing practice ZIP/JSON backups still exclude Composer. Projects remain device-local until C7 supplies portable recovery. Never uninstall or clear data for an update.
