# Inspirations

Library opens Media by default. Switch to Inspirations to read an included work or add to the personal collection. Write or paste text, take a photo with the installed camera app, or choose an original PDF, JPEG, PNG, WebP, UTF-8 TXT or Markdown file. Markdown opens as editable plain text. Saving changes to imported text updates the stored text. The Android source document remains under its original provider.

Title is required. Author, source, category and personal note are optional. Edits retain the entry ID. Visual attachments are retained until confirmed removal and Save. Deleting an entry requires confirmation. Saved content is available offline. Original size limit is 20 MiB. PDF and image validation uses the same page, dimension and decoding rules as Media. Drafts remain in memory through Activity recreation. Save before closing the process.

Room 23 stores the collection separately. New files belong to Inspirations. If a valid Media Library original has identical bytes, the Inspiration links to it by ID. That Library original remains protected while referenced and still belongs to Media after the Inspiration link is removed. Complete ZIP v7 preserves the collection and owned originals. See [Backup format and recovery](../BACKUP_FORMAT.md#complete-portable-zip-v7).

## Included works

All five included works are read-only UTF-8 assets in the APK and available offline. They have no seeded database rows. The first two selections use Hugh G. Evelyn-White's 1914 English translation of *Hesiod, the Homeric Hymns and Homerica* (Loeb Classical Library, William Heinemann and Macmillan). The 1914 edition is in the public domain. The app uses the translated text with line range markers and editorial footnotes omitted.

- Anonymous, *Homeric Hymn 25, To the Muses and Apollo*, lines 1–7. [1914 edition transcription](https://www.gutenberg.org/files/348/348-h/348-h.htm#chap60)
- Hesiod, *Theogony*, the opening invocation, lines 1–115. [1914 edition transcription](https://www.gutenberg.org/files/348/348-h/348-h.htm#chap26)

- Anonymous, traditionally attributed to Orpheus, *Orphic Hymn 76, To the Muses*, translated by Thomas Taylor. The London 1792 reissue, *The Hymns of Orpheus*, numbers this hymn LXXV because Taylor includes the invocation to Hecate in the opening address to Musaeus. The text includes the original incense heading and all 22 verse lines, with page and note markers omitted. [1792 edition](https://books.google.com/books?id=_Y--MMpjYvMC) · [Internet Sacred Text Archive transcription](https://original.sacred-texts.com/cla/hoo/hoo80.htm)
- John Dryden, *A Song for St. Cecilia's Day, 1687*. George Gilfillan, ed., *The Poetical Works of John Dryden*, vol. II (1855). Includes all seven stanzas and the Grand Chorus. The transcription's “rail” is corrected to “ran”. [Project Gutenberg no. 11578](https://www.gutenberg.org/cache/epub/11578/pg11578.html#id00531)
- Nicholas Brady, *Hail! Bright Cecilia, 1692*, set by Henry Purcell. The complete verse is transcribed from “Ode on St. Cecilia's Day” in John Nichols, ed., *A Select Collection of Poems*, vol. V (London, 1782), pp. 302–306. This edition gives the poem as continuous verse with its Grand Chorus. The transcription retains verse breaks and uses modern letter forms for the long s. The public-domain 1897 Novello vocal score edited by J. A. Fuller Maitland documents the musical setting. [Nichols facsimile](https://archive.org/details/selectcollection05nich/page/302/mode/2up) · [Sibley Music Library score](https://urresearch.rochester.edu/institutionalPublicationPublicView.action?institutionalItemId=17334)

The packaged texts omit editorial footnotes and commentary. Personally supplied copies of Ron Miller's *Practice Prayer*, Monk's advice in Steve Lacy's handwriting, and Tolkien's *Ainulindalë* can be added through the personal collection.
